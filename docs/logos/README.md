# Logos

An SVG per adopter, named after them — `acme.svg`, `globex.svg`.

The rules, so the page stays tidy:

- SVG, not PNG. The site is text and vector, and it stays that way.
- Monochrome, or one colour that reads on both a light and a dark page.
- About 32px tall. Give it a `viewBox` and no fixed width.
- No text in the logo. The name goes next to it.

A logo is optional. The name in the table is what matters.
