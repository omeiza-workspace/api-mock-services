## Adding yourself

Open a pull request that adds a row to the table above. That is all — no
form, no email, no account.

A row looks like this:

```markdown
| Acme Ltd | The payment tests in our Laravel checkout | 2026 |
```

If you would like a logo next to your name, put an SVG in
[`docs/logos/`](https://github.com/omeiza-workspace/api-mock-services/tree/main/docs/logos)
— monochrome, about 32px tall — and link it:

```markdown
| [![Acme](https://raw.githubusercontent.com/omeiza-workspace/api-mock-services/main/docs/logos/acme.svg)](https://acme.example) | The payment tests in our Laravel checkout | 2026 |
```

That is the whole process. The list is a pull request, so it is public,
reviewable, and nobody has to approve a form.

## What this list is for

Two things, both free:

- It tells a developer looking at the project who else is on it, which is
  the difference between a tool and a hobby.
- It is the record of real use. The list grows by pull request, so it cannot
  be inflated — every entry is public, dated, and attributable.

If you use the mocks and would rather not be listed, that is completely
fine. The list is for the people who want to be found.
